# Kek Lapese

A responsive, static bakery landing page for Kek Lapese. It uses plain HTML, CSS, and JavaScript, with no database or build step. The pixel-inspired details are original CSS artwork and typography; there are no generated cake photos being presented as real products.

## Assets to add later

- The supplied Kek Lapese logo and banner are used in the page header and hero. The catalogue uses generated voxel-inspired cake illustrations from the flavour sprite sheet. These are illustrative graphics, not photographs of the actual cakes.
- The WhatsApp order form is prefilled for Nillia (`+60 14-390 3413`) or Mattheus (`+60 17-857 2613`) at RM15 per whole loaf. It opens a message for the customer to review and send; it does not send automatically.
- Pre-orders are Sunday–Thursday. The form has no backend and stores no customer information.

## Run locally

Open `index.html` in a browser, or serve the `outputs` directory with any static file server.

## GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the static site from the repository root whenever changes land on `main` and can also be started manually.
